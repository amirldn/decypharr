# Contributing

This is Amir's custom Decypharr fork, based on upstream v2.6 with TorBox reliability changes from KGBos and local authentication/mount fixes.

See [the integration notes](docs/operations/kgbos-v26-integration.md) for provenance, behavior changes and validation. Use feature branches and describe the resulting behavior and validation in pull requests. Deployment to the server is a separate action from publishing source changes.
